Il Viaggio della Scrivania — Mappa dei 10 Capitoli

Come la scena 3D evolve sezione per sezione. Scroll = progresso nel tempo. La camera si avvicina/allontana dalla scrivania rivelando nuovi dettagli.

wireframe ─────────── solido
00

INTRO — "Hello"

100% wireframe

Scena: Buio totale. Un singolo punto luminoso si espande in una griglia wireframe. Una scrivania scheletrica emerge dal nulla — solo linee, nessun materiale. Un vecchio CRT si accende con un cursore lampeggiante.

Camera: Zoom-in lento dal buio verso la scrivania. Interazione: Click sul CRT → appare "Hello World" con typing animation.

01

LA PRIMA RIGA — "Il primo Hello World"

90% wireframe

Scena: La scrivania wireframe ora ha un blocco note e una tazza (wireframe). Il CRT mostra codice HTML. Le linee della scrivania iniziano ad avere un leggero spessore/glow. Fogli di appunti sparsi (wireframe piatti).

Camera: Angolo laterale, focus sul monitor. Click: Monitor → typing animation del primo codice HTML/CSS/JS.

02

AULAB — "Dove è iniziato davvero"

75% wireframe

Scena: Il CRT diventa un monitor piatto (morph). Appare una tastiera vera (semi-wireframe, tasti distinguibili). Libri di programmazione impilati. Un calendario/orologio con "847 ore". Le superfici iniziano ad avere un fill leggero (semi-trasparente).

Camera: Si alza leggermente, visione più ampia. Click: Libri → stack tecnologico appreso. Orologio → contatore ore animato.

03

BACKEND — "La lotta con PHP"

60% wireframe

Scena: Il monitor mostra un terminale con errori (testo rosso). La scrivania si "incrina" momentaneamente — linee glitch. Poi si stabilizza: appare un server rack wireframe dietro il desk. Database schema fluttuante sopra la scrivania. Le superfici oscillano tra wireframe e solido (instabilità = lotta).

Camera: Shake leggero, poi stabilizzazione. Click: Server → schema DB animato. Monitor → evoluzione del codice.

04

REACT — "Quando ho capito"

50% → momento di svolta

Scena: 💡 Momento chiave: Il monitor si illumina con il logo React che ruota. Un'onda di "solidificazione" parte dal monitor e attraversa la scrivania — wireframe → solido in tempo reale. Nuovi oggetti: secondo monitor, cuffie, pianta. Tutto diventa più definito. È il punto di svolta visivo.

Camera: Zoom drammatico sul monitor, poi pullback per rivelare il setup ampliato. Click: Monitor → component tree interattivo.

05

PRIMO LAVORO — "La realtà"

40% wireframe

Scena: La scrivania è ora in un "ufficio" — muri semi-trasparenti appaiono. Post-it colorati sulla parete. Slack/chat sul secondo monitor. Un badge aziendale appoggiato. Git graph fluttuante (contribuzioni). La scrivania è ora per lo più solida con dettagli wireframe residui.

Camera: Leggero zoom-out per mostrare l'ambiente. Click: Badge → prima esperienza. Git graph → contribuzioni animate.

06

AI — "Non magia, solo strumenti"

25% wireframe

Scena: Un ologramma/AI assistant fluttua sopra la scrivania (wireframe trasparente che pulsa). Split-screen sui monitor: coding manuale vs AI-assisted. Particelle che connettono l'ologramma al codice. La scrivania è quasi completamente solida.

Camera: Focus sull'ologramma, poi sui monitor. Click: Ologramma → prompt reali utilizzati. Monitor → confronto produttività.

07

ANIMAZIONI — "Dare vita al web"

15% wireframe

Scena: La scrivania "prende vita" — gli oggetti hanno micro-animazioni (la pianta cresce, la tazza fuma, le luci pulsano). Un monitor mostra un'animazione GSAP in loop. Particelle colorate riempiono l'aria. È la sezione più "viva" e colorata. Tutto quasi solido con glow effects.

Camera: Orbita lenta attorno alla scrivania. Click: Monitor → demo animazione interattiva. Particelle → FPS counter.

08

NEXT.JS — "Maturità tecnica"

5% wireframe

Scena: Setup professionale: ultrawide monitor, MacBook, standing desk. Lighthouse scores fluttuanti (cerchi animati). Deploy pipeline visualizzata come un "tubo" luminoso che esce dal monitor verso il cloud. Architettura del progetto come mappa 3D. Quasi tutto solido — materiali PBR con riflessi.

Camera: Vista professionale, angolo pulito. Click: Lighthouse → scores animati. Pipeline → step del deploy.

09

THREE.JS — "La nuova frontiera"

0% wireframe — 100% solido

Scena: 🌟 Climax: La scrivania diventa completamente solida e dettagliata — materiali PBR pieni, riflessi, ombre. Il monitor mostra una scena Three.js (inception!). La scrivania stessa inizia a "deformarsi" in modi creativi — il tavolo si piega, gli oggetti levitano. La padronanza del 3D = libertà di rompere le regole.

Camera: Orbita libera, prospettive impossibili. Click: Monitor → galleria esperimenti 3D. Oggetti → deformazione interattiva.

10

OGGI & DOMANI — "Non un guru, solo uno che non smette"

Oltre il solido — emissivo

Scena: La scrivania è al suo massimo splendore. Poi — zoom out lento. La camera si allontana rivelando che la scrivania è una piccola isola luminosa in un vasto spazio scuro. Altre "isole" in lontananza (progetti futuri, possibilità). Tech stack come costellazione orbitante. CTA finale luminoso.

Camera: Grand zoom-out, dalla scrivania all'universo. Click: Costellazioni → tech stack. Isole lontane → link portfolio/contatti.
