Workflow Produzione Asset 3D

Come creiamo concretamente i modelli per ogni capitolo — dal wireframe puro al PBR finale

🎯 Strategia a 3 Livelli

Non serve creare tutti i modelli in Blender. Il trucco è usare l'approccio giusto per ogni livello di materialità:

▢
LIVELLO 1
Cap. 00–02 (100%–75% wireframe)

Procedurali in Three.js

Geometrie create in codice. Nessun file esterno. Come il tuo WizardScene attuale.

→ BoxGeometry per scrivania/monitor
→ EdgesGeometry per wireframe visibile
→ CylinderGeometry per tazza/gambe
→ PlaneGeometry per fogli/schermi
→ LineSegments per decorazioni
✓ Zero asset esterni • Massimo controllo • Leggerissimo
◧
LIVELLO 2
Cap. 03–06 (60%–25% wireframe)

Low-Poly da Marketplace

Modelli low-poly gratuiti/economici, ottimizzati. Li usiamo come base per la versione "semi-solida".

→ Sketchfab (gratis CC, low-poly)
→ poly.pizza (low-poly gratis)
→ Kenney.nl (game assets CC0)
→ retro_computer.glb già c'è!
→ Ottimizzati con gltf-transform
⚡ Rapido • Budget ~€0-50 • Buon dettaglio
■
LIVELLO 3
Cap. 07–10 (15%–0% wireframe)

Custom Blender / AI-Assisted

Per i capitoli finali dove serve qualità alta, modelli custom con PBR materials e dettagli.

→ Blender (modellazione custom)
→ Meshy.ai / Tripo3D (AI → 3D)
→ Export GLTF con Draco compression
→ PBR textures (roughness, metalness)
→ Baked lighting per performance
🎨 Max qualità • Richiede più tempo • Effetto wow

🔄 Pipeline di Ottimizzazione GLTF

Da modello scaricato a asset pronto per il web
1. Download .glb/.gltf
→
2. Blender: decimate + cleanup
→
3. gltf-transform: optimize
→
4. Draco compress
→
✓ /public/models/
# Comandi utili
npx @gltf-transform/cli optimize input.glb output.glb
npx @gltf-transform/cli draco input.glb output.glb
npx @gltf-transform/cli dedup input.glb output.glb # rimuove duplicati
npx gltfjsx output.glb # genera componente React Three Fiber

🤖 Opzione AI per Modelli Custom

Per oggetti unici che non trovi nei marketplace, puoi usare tool AI text-to-3D. Qualità crescente, ideali per low/mid-poly:

Meshy.ai

  • Text/image → 3D model
  • Export GLB con PBR textures
  • 200 crediti gratis/mese
  • Buono per oggetti organici

Tripo3D

  • Text/image → high quality 3D
  • Molto buono per oggetti hard-surface
  • Retopology automatica
  • Ideale per tastiere, monitor, gadget
